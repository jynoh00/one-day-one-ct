## 문제 정보

- 기타 문제
- 사용 언어: C++
- 풀이 날짜: 2026-07-16

## 문제 요약

- N, M크기의 맵 존재
- (1, 1) ~ (N,M)까지 이동하는 것이 목표
- 이동 방식
    - 주사위를 던진다. (결과 1 ~ 6)
    - 나오는 눈금에 따라 `(x + dice, y)` or `(x, y + dice)`로 이동 가능하다.
- 맵 바깥으로 이동 불가
- 휴식 공간을 거치지 않고 목표 지점까지 이동하는 모든 경우의 수 출력
    - 최종 정답 경우의 수를 `10^9 + 7`로 나눈 나머지를 출력할 것


## 접근 방법

1. bfs 풀이

처음 문제를 접했을 때, 노드를 기준으로 이동하는 것이라 생각하여 bfs를 활용하여 문제를 풀어보았다.

```cpp
queue<pair<int, int>> q;

...

while {
    q.front가 N,M인가?
        ans++, q.pop, continue;

    q.front 주변 노드 확인
        q에 삽입

    q.pop
}

```

위 방법으로 진행한다 하였을 때, `(1, 1)`에서 `(N, M)`까지 조건에 맞게 이동 가능한 모든 경우의 수를 구하게 된다.

러프하게 생각해봤을 때도 나올 수 있는 눈금의 경우의 수는 모두 6가지이고,

각 눈금에서 나오는 경우의 수와 다음 눈금에서 나오는 경우의 수가 모두 `6*6` 조합의 경우의 수를 측정하게 된다.

뿐만 아니라 나온 눈금을 `x` 증가로 사용할지, `y` 증가로 사용할지로 `2`가지 경우가 추가로 생기는 것이기에

종합적인 `1, 1` ~ `N, M`까지의 총 경우의 수는 아득히 시간 제한 범위를 넘어가게 되었다.


2. 이전 계산 결과 활용 방식

`(1, 1)`에서 `(2, 3)`을 거쳐 `(10, 10)`으로 간다고 가정해보자.

- `(1, 1)`에서 `(2, 3)`으로 가는 경우의 수 : `p`개

- `(2, 3)`에서 `(10, 10)`으로 가는 경우의 수 : `q`개

총 구하려는 `(1, 1)`에서 `(10, 10)`으로 가는 경우의 수는 다른 이동 방식들에서 `p + q`를 더한 값이라 할 수 있다.

즉, 어떤 `(x, y)` 위치에 도달하는 경우의 수는 해당 노드로 도달할 수 있는 노드들을 파악해야한다.

```
x-1, y
x-2, y
x-3, y
x-4, y
x-5, y
x-6, y
x, y-1
x, y-2
x, y-3
x, y-4
x, y-5
x, y-6
```

결과적으로 다음과 같이 점화식을 세울 수 있었다.

`dp[x][y] = dp[x-1][y] + dp[x-2][y] + dp[x-3][y] + dp[x-4][y] + dp[x-5][y] + dp[x-6][y] + dp[x][y-1] + dp[x][y-2] + dp[x][y-3] + dp[x][y-4] + dp[x][y-5] + dp[x][y-6]`

```cpp
for (int d = 1; d <= 6; d++) {
        if (nodeCheck(i - d, j)) {
            dp[i][j] += (dp[i - d][j]) % MOD;
            dp[i][j] = dp[i][j] % MOD;
        }
    }

    for (int d = 1; d <= 6; d++) {
        if (nodeCheck(i, j - d)) {
            dp[i][j] += (dp[i][j - d]) % MOD;
            dp[i][j] = dp[i][j] % MOD;
        }
    }
```

## 풀이

```cpp
void solve() {
    dp[1][1] = 1;

    for (int i = 1; i <= N; i++) {
        for (int j = 1; j <= M; j++) {
            calc(i, j);
        }
    }

    cout << dp[N][M] << endl;
}

void calc(int i, int j) {
    int ans = 0;

    for (int d = 1; d <= 6; d++) {
        if (nodeCheck(i - d, j)) {
            dp[i][j] += (dp[i - d][j]) % MOD;
            dp[i][j] = dp[i][j] % MOD;
        }
    }

    for (int d = 1; d <= 6; d++) {
        if (nodeCheck(i, j - d)) {
            dp[i][j] += (dp[i][j - d]) % MOD;
            dp[i][j] = dp[i][j] % MOD;
        }
    }


}

bool nodeCheck(int x, int y) {
    if (x < 1 || x > N || y < 1 || y > M) return false;
    if (map[x][y] == 1) return false;

    return true;
}
```

초기에 노드간 이동에 대한 경우의 수를 측정하는 문제이기에, DFS-BFS가 떠올랐고 이를 적용했다.

하지만 결과적으로 DFS, BFS 방식의 경우 위 문제에서 탐색 종료 조건이 마지막 노드에 도착하는 것이기에, <br/>
결과적으론 가능한 모든 경우의 수를 하나씩 다 찾는 완전 탐색으로 알고리즘 문제를 풀려한 것이었다.

문제에 대한 접근 자체가 틀렸다고 할 수 있었다.

이후 해당 문제는 DP 알고리즘이란 것을 확인하였고, DP가 일반적으로는 작은 문제를 통해 전체 문제를 해결하는 개념이지만<br/>
해당 문제에서 해결한 근본적 원리처럼 동일 연산이 반복되는 경우 앞선 계산의 결과를 기억하는 문제에서도 DP를 고려해보자란 생각이 들었다.


## 복잡도

- 시간 복잡도: `O(NM)` // `N, M <= 500`
