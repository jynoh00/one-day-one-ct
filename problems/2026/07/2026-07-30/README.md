## 문제 요약

- 한번에 1칸, 또는 2칸을 뛸 수 있다.

- 칸이 총 4개 있을 때,

```
(1칸, 1칸, 1칸, 1칸)
(1칸, 2칸, 1칸)
(1칸, 1칸, 2칸)
(2칸, 1칸, 1칸)
(2칸, 2칸)
```

- 5가지 방법으로 맨 끝 칸에 도달할 수 있다.

- 멀리뛰기에 사용될 칸의 수 n
- 끝에 도달하는 방법이 몇 가지인지 알아내, 여기에 1234567를 나눈 나머지를 리턴하는 함수

- 제한 사항
    - n은 1 이상, 2000 이하인 정수입니다.


## 접근 방법

1. `DP`

그냥 보자마자 DP 밖에 생각 안났다.
