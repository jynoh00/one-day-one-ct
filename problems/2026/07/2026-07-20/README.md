## 문제 요약

- 폭격 미사일은 가로 (x축에 평행) (s, e)
- 요격 미사일은 세로 (y축에 평행) x좌표에 걸쳐있는 모든 폭격 미사일을 관통. 한번에 요격 가능

- s, e는 정수
- s, e로 표현된 폭격 미사일은 s, e 위치에서 발사하는 요격 미사일로 요격 불가
- 요격 미사일은 실수 좌표에서도 발사 가능

- 폭격 미사일의 범위 목록 targets
- 모든 미사일을 요격하기 위해 필요한 요격 미사일 수의 최솟값을 return

`[[4,5],[4,8],[10,14],[11,13],[5,12],[3,7],[1,4]]` -> `3`

=> 맞추기만 하면 된다. 끝자리는 카운트되지 않는다.

## 풀이

```cpp
sort(targets.begin(), targets.end(),
    [](const vector<int>& a, const vector<int>& b) {
        return a[1] > b[1];
    }
);

range.first = targets[0][0];
range.second = targets[0][1];

for (int i = 1; i < targets.size(); i++) {
    int tmpLeft = targets[i][0];
    int tmpRight = targets[i][1];
    
    if (range.first < tmpRight) { // 중복 킬 가능 영역, 마지막 원소가 아닌 경우
        range.second = tmpRight;
        range.first = range.first <= tmpLeft ? tmpLeft : range.first;

        continue;
    }

    answer++;
    range.first = tmpLeft;
    range.second = tmpRight;
}
```

해당 문제의 경우, 나름의 알고리즘이 있을 것이다 생각하고 머리를 계속 굴려보고 시간 복잡도도 생각해보며 풀어보았지만 실패하였다.

이후 정해놓은 시간을 넘어 고민하게 되어, 어떤 알고리즘을 사용하는지 확인하는 과정을 거쳤고 단순 그리디임을 확인하였다.

이후 각 벡터 내부 원소의 값들을 기준으로 정렬을 진행하였고, 정렬된 결과를 바탕으로 내부 로직을 생각하여 문제를 해결하였다.

내부 로직은 다음처럼 생각하였다.

1. 벡터를 순회하며 이전 범위와 현재 미사일 범위를 비교한다.
2. 겹치는 부분이 존재한다면 새로운 범위(겹치는)를 계산한다.
3. 겹치는 부분이 존재하지 않는다면 이전까지의 미사일들을 요격하는 카운트를 증가, 새로운 범위를 계산한다.

## 복잡도

- 시간 복잡도: `O(NlogN)` // 정렬 과정 (sort)

## 회고

### 잘한 점

- 문제를 그래도 최대한 고민해본 것
- 정해진 시간을 넘겼을 때 바로 정답이 아닌 사용 알고리즘만 확인하고 문제를 해결한 것
- 내부 로직을 구현할 때 비교적 빠르게 작성한 것

### 어려웠던 점

- 그리디 문제는 그리디로 풀 수 있는지 아는게 가장 어려운 것 같다.
- 이번 문제 역시 제대로된 알고리즘이 있어야 시간 복잡도를 해결할 수 있다 생각해보느라, 기본적인 그리디를 생각하지 못했다.
- 벡터 내부 정렬을 수행할 때 단일 원소가 아니라 각 원소가 가지는 값 기준 정렬이 낯설었다.

### 새롭게 알게 된 점

- 모던 `C++`에도 람다 함수가 존재하며, 이를 `sort`와 엮어 특정 조건을 기준으로 정렬할 수 있다.

### 개선할 점

- 그리디는 결국 `지금 고른 선택이 이후 선택의 가능성을 최대한 많이 남기는가?`임을 확인하자
- 그리디 뿐만 아니라 많은 코테 문제는 정렬과 함께 한다. 람다를 이용한 정렬 역시 기억해두고 활용하자.
