## 문제 요약

- 귤 수확
    - 전체 귤 중 k개를 골라 상자 하나에 담아 판매

- 크기 일정 x
    - => 크기별 분류했을 때 서로 다른 종류의 수를 최소화

- 8개 수확
    - 1, 3, 2, 5, 4, 5, 2, 3
- => 6개 판매하고 싶다면, 크기가 1이랑 4인 귤 제외 => 6개
    - <- 크기 종류가 2, 3, 5로 총 3가지
- = 서로 다른 종류(크기)의 최소

- 한 상자에 담으려는 귤의 개수 K개
- K <= 100,000
- tangerine <= 10,000,000


## 접근 방법

1. 초기 오름차순 정렬 생각

```
    크기  개수
map<int, int> => vector<pair<int, int>>
개수 순으로 정렬, 개수가 가장 작은 크기 제거
```

초기에 위와 같은 구조를 생각하였다.

각 귤의 크기를 키값으로 가져가며 동일 크기를 가진 귤의 수를 카운트 <- by map

이후 초기화가 완료된 맵을 페어 벡터로 전환하여 개수 순으로 정렬 실행 => 오름차순

벡터를 순회하며 전체 개수에서 해당 원소의 개수를 뺐을 때 값이 `k`와 같거나 작아지는 지점이 정답 포인트

2. 최종 내림차순으로 구현

위와 동일 풀이이긴 하나,

코드를 구현하며 오름차순보다는 내림차순으로 개수를 세는 방식이 더 효율적이라 생각하였다.

- 오름차순의 경우, 전체 개수에서 값을 빼다 적은 경우와 동일한 경우 개별로 다루어야하나
- 내림차순은 값을 넘어가는 경우와 동일한 경우에 동일 로직으로 처리가 가능하기에 분기가 줄어든다.
