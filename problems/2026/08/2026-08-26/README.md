## 문제 요약

- `progresses` : 기능 개선 진행 척도 배열
- `speeds` : 개발 진행 속도
- 인덱스의 순서는 배포 조건
    - 앞선 기능 개발이 모두 완료되어야 현재 기능 개발이 배포될 수 있다.

일정 주기마다 `speeds`의 값만큼 `progresses`가 증가할 때,<br/>
각 배포마다 몇 개의 기능 개발이 완료되는지 나타내는 벡터를 반환하라.
